## Decisioni aperte che bloccano le fasi 3–4

Censite nell'audit (sezione 6). Le principali:

1. **Modello di parcella** (fissa / % su AUM / ibrida) — è anche una decisione di
   brand, perché "Sai sempre quanto paghi. E perché" è un pilastro del messaging.
   Collegata a `02-modello-previsionale/RICALIBRAZIONE-SCF.md`.
2. **Ruolo dell'app/portale** nel nuovo posizionamento SCF.
3. **Brand aziendale vs personal brand dei fondatori** come volto pubblico.
4. **Conferma della tagline** "Oltre i limiti comuni" dopo la ricerca competitor.
