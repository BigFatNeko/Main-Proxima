# Proxima — Hub Centrale

Repository centrale di **Proxima**, SCF (Società di Consulenza Finanziaria)
italiana *fee-only* per risparmiatori con meno di €100.000.

Tutto il materiale operativo è organizzato sotto **[`PROXIMA-Main/`](./PROXIMA-Main/)**:

- **`01-strategia/`** — piano di lancio €180K, struttura societaria SCF, iter OCF, costi, tassazione, competitor
- **`02-modello-previsionale/`** — modello funnel costi/ricavi (da ricalibrare per SCF fee-only)
- **`03-marketing/`** — strategia + libreria skill (SEO, CRO, copywriting, paid ads, launch…)
- **`04-briefing/`** — copia della pipeline di briefing finanziario (⚠ la versione *live* gira via GitHub Actions)
- **`05-branding/`** — asset di brand e landing page

Per note tecniche e avvisi (in particolare sulla **pipeline briefing in produzione**)
vedi [`CLAUDE.md`](./CLAUDE.md).
